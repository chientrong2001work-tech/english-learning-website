# EngUp — Website học tiếng Anh

Website học tiếng Anh đơn giản, xây dựng bằng React + TypeScript + Vite + Tailwind CSS.

## Tính năng

- **Flashcard từ vựng**: lật thẻ để xem nghĩa, nghe phát âm, lọc theo chủ đề (giao tiếp, du lịch, công việc, ẩm thực), đánh dấu từ đã thuộc — tiến trình được lưu trong trình duyệt.
- **Quiz trắc nghiệm**: 10 câu hỏi ngẫu nhiên mỗi lượt, chọn nghĩa đúng của từ, chấm điểm và lưu điểm cao nhất.
- **Mẹo ngữ pháp**: các cấu trúc ngữ pháp cơ bản thường gặp, kèm ví dụ.

## Bắt đầu

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```
